# 🚀 One-Click Jenkins Installation

This project provides a **one-click installation script** for Jenkins on EC2 / Linux systems.

---

## ⚠️ Supported OS

This script works **ONLY on:**
- Ubuntu
- Debian (and Debian-based systems)

❌ It will NOT work on:
- Amazon Linux
- CentOS / RHEL
- Arch Linux
- macOS / Windows

---

## 📥 How to Install (One Click)

Run the following commands:

```bash
chmod +x script.sh
sudo bash script.sh
